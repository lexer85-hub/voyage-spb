# Проверка первой версии

Проверено 08.10.2026 в браузере Codex:

- Загрузка страницы и локальных изображений; ошибок JavaScript в консоли не обнаружено.
- Адаптация на ширинах 320, 375, 768, 1024 и 1440 пикселей. Горизонтальной прокрутки страницы нет. На узких экранах исправлено переполнение первого блока.
- Меню на телефоне: открытие, закрытие, закрытие Escape с возвратом фокуса.
- Карточки товаров: показ обратной стороны при наведении мыши, возврат при уходе курсора; переворот с клавиатуры через Enter/пробел и возврат через Escape. На ширине 375 пикселей списки не обрезаются, горизонтальной прокрутки нет. Сенсорный обработчик добавлен; физическое устройство отдельно не тестировалось.
- Раскрытие реквизитов и FAQ.
- Реальное скачивание PDF по кнопке, совпадение опубликованной копии с исходным PDF.
- Встраиваемая карта загружается и показывает метку «Вояж-СПб» в центре. Автоматическое раскрытие карточки отключено: используется центрирование по координатам без выбора организации.
- Локальные ссылки и якоря, уникальность ID, один H1, синтаксис JavaScript и JSON-LD.
- Реквизиты в HTML сверены с данными заказчика; файл реквизитов ранее проверен визуально.

Ограничения проверки:

- Проверка адаптации выполнена эмуляцией размеров окна; физические iPhone/Android, Safari и Firefox отдельно не тестировались.
- Звонки, отправка почты, фактическое построение поездки и переписка не выполнялись. Ссылки на телефон и почту проверены в разметке.
- MAX — обозначенная заглушка, без вымышленного профиля.
- SEO-разметка подготовлена, индексация поисковиками возможна после публикации и не гарантируется.
- На публичный сервер файлы не загружались. HTTPS, перенаправления и работа на реальном домене потребуют проверки при запуске.

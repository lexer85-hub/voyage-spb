# Вояж-СПб — сайт магазина автозапчастей

Одностраничный сайт круглосуточного магазина «Вояж-СПб» в Санкт-Петербурге.
Основной ассортимент — запчасти для ВАЗ, ГАЗ и УАЗ. Адрес магазина: улица Маршала
Говорова, 10.

Сайт написан на HTML, CSS и обычном JavaScript. Сборщик, CMS, база данных и серверная
логика не нужны: папка `dist/` содержит готовый сайт. На странице нет корзины,
платежей или форм отправки заявок. Кнопки открывают телефон, мессенджеры, почту
или скачивание PDF.

Описание соответствует локальной версии после аудита **24 октября 2026 года**.
Аудит не публиковался; содержимое GitHub Pages может отличаться.

## Разделы страницы

1. **Шапка.** Логотип, навигация, телефон и мобильное меню.
2. **Первый экран.** Заголовок «За запчастями — в любое время», кнопки звонка,
   MAX и WhatsApp. На широком экране — тормозной диск и декоративные линии.
   Ниже расположен блок автомобильных заводов ВАЗ, ГАЗ, УАЗ.
3. **Ассортимент** (`#assortment`). Девять товарных групп со списками товаров
   и кнопка «Уточнить наличие».
4. **О магазине** (`#advantages`). История компании, шесть преимуществ и
   встроенные отзывы Яндекс Карт.
5. **Для бизнеса** (`#business`). Условия для СТО, автопарков и организаций,
   НДС, ЭДО, поставки по заявкам. Скачать реквизиты и написать о сотрудничестве.
6. **Ждём вас** (`#contacts`). Фотография входа, адрес, время пешком от метро
   «Путиловская» и «Кировский завод», Яндекс Карта.
7. **Подвал.** Название организации, текущий год, ИНН, ОГРН и переход вверх.
   На компьютере также показаны логотип и ссылка на реквизиты.

## Запуск локально

В терминале из корня проекта:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

Открыть [локальный сайт](http://127.0.0.1:8765/).
Терминал с сервером должен оставаться запущенным. Остановка — `Ctrl+C`.
Если порт уже занят существующим сервером сайта, второй запуск не требуется.

Сервер доступен только на этом компьютере. Основной контент и шрифты локальные;
для карты, отзывов и переходов в мессенджеры нужен интернет.

## Структура проекта

```text
dist/                         Готовый сайт и одновременно исходный код
  index.html                  Тексты, ссылки, SVG-иконки кнопок, SEO и JSON-LD
  styles.css                  Стили, сгруппированные по разделам
  script.js                   Меню, раскрытие карточек, и текущий год
  assets/                     Используемые SVG, фотография, WOFF2 и лицензия
  downloads/                  PDF с реквизитами
  robots.txt                  Настройки обхода сайта
  sitemap.xml                 Карта сайта для поисковиков
branding/                     Исходники и варианты фирменного оформления
  contact-icons/              Исходные иконки мессенджеров и сведения об источниках
  previous/                   Предыдущие варианты логотипа
output/imagegen/              Исходные изображения обработки фото и описания
qa-visual/                    Снимки предыдущих визуальных проверок
scripts/check_site.py         Проверка разметки и локальных ссылок
QA.md                         Результат текущего аудита и известные ограничения
docs/QA-history.md            История проверок старых версий
backups/                      Локальные резервные копии; исключены из Git
.github/workflows/pages.yml   Публикация папки dist на GitHub Pages
```

`branding/`, `output/`, документы и резервные копии не загружаются браузером
и не входят в публикацию. Они сохранены как исходные материалы и история работы.

## Где менять содержимое

- **Тексты и ассортимент:** соответствующий раздел `dist/index.html`.
  Карточка — элемент `article.category`, список товаров — `category-content`.
- **Контакты:** ссылки `tel:`, `mailto:`, MAX и WhatsApp в HTML. При смене телефона,
  адреса или графика нужно также обновить JSON-LD в начале файла.
- **Реквизиты:** заменить `dist/downloads/voyazh-spb-requisites.pdf`, проверить
  ИНН и ОГРН в подвале и `taxID` в JSON-LD.
- **Фотография:** `dist/assets/storefront.jpg`. Текущая фотография обработана:
  убраны посторонние предметы и улучшен внешний вид здания.
- **Логотип и значок вкладки:** `dist/assets/logo.svg` и `favicon.svg`.
- **Цвета:** переменные в начале `dist/styles.css`. Основные цвета — фиолетовый
  `#634583`, тёмный фиолетовый `#352443`, бирюзовый `#26CAD3` и светлый `#F6F4F8`.
- **Поведение:** именованные функции `initMobileMenu`, `initCatalogue`,
  `initAdvantages` в `dist/script.js`.

CSS разделён комментариями на базовые элементы, кнопки, шапку, первый экран,
ассортимент, описание магазина, сотрудничество, контакты и подвал.
Правила внутри разделов сохраняют порядок каскада: при переносе `@media` или
объединении селекторов нужно повторно проверить адаптивную версию.

Форматирование: два пробела, UTF-8, перенос строки LF. Настройки для редакторов
находятся в `.editorconfig`, для Prettier — в `.prettierrc.json`.
Зависимости для работы сайта устанавливать не нужно.

После правок CSS или JavaScript меняйте значение `?v=` у соответствующего
подключения в HTML. Это помогает браузерам получить обновлённый файл.

## Адаптация для разных экранов

- До **1000 px** основная навигация заменяется мобильным меню.
- До **960 px** карточки ассортимента сворачиваются. На большом экране все списки
  раскрыты. Отзывы переходят под описание магазина.
- Диск скрывается до **960 px**, при вертикальной ориентации и на сенсорном
  экране небольшой высоты.
- До **800 px** убраны фоновые линии, преимущества собраны под кнопкой
  «Наши преимущества», реквизиты представлены одной кнопкой без оформления листа.
  Подвал упрощён, адрес и карта размещаются друг под другом.
- До **540 px** появляется закреплённая панель «Позвонить / Как добраться».

При отключённом JavaScript товарные списки и преимущества остаются в HTML
раскрытыми. При включённом JavaScript кнопки сообщают состояние через
`aria-expanded`; меню закрывается по Escape с возвратом фокуса.

Карта и отзывы загружаются от сторонних сервисов через `iframe` с отложенной
загрузкой. Их содержимое, реклама и доступность не контролируются кодом сайта.
24 октября 2026 года карта возвращена с 2ГИС на Яндекс. Масштабирование iframe,
нужное только для карточки 2ГИС, удалено. Карта занимает всю доступную область
на компьютере и телефоне. Под iframe сохранена запасная ссылка на магазин.
Виджет может показывать рекламу; настройки рекламы определяются Яндексом.

Локальные шрифты — Manrope в WOFF2. Лицензия сохранена в
`dist/assets/manrope-license.txt`. Исходники фирменных знаков и сведения об их
происхождении сохранены в `branding/`.

## Проверка после изменений

```sh
python3 scripts/check_site.py
```

Проверка на стандартной библиотеке Python ищет отсутствующие локальные файлы,
битые якоря, повторные ID, неверные ARIA-ссылки, изображения без `alt`, iframe
без названия и ошибки JSON-LD. Она не заменяет браузерную проверку.

Если установлен Node.js, проверить синтаксис скрипта можно отдельно:

```sh
node --check dist/script.js
```

В браузере проверьте широкое окно и телефон: меню, раскрытие карточек и
преимуществ, отсутствие горизонтальной прокрутки, скачивание реквизитов,
загрузку карты и отзывов. Результаты последней проверки — в [QA.md](QA.md).

## Публикация

[Репозиторий GitHub](https://github.com/lexer85-hub/voyage-spb) ·
[Сайт GitHub Pages](https://lexer85-hub.github.io/voyage-spb/).

Workflow `.github/workflows/pages.yml` публикует только `dist/` после изменения
этой папки в ветке `main` или ручного запуска workflow. Отправка локальных
изменений в `main` может запустить публикацию. В рамках текущего аудита
отправка изменений и публикация не выполнялись.

SEO-адреса в HTML, `robots.txt` и `sitemap.xml` используют GitHub Pages.
При переходе на другой домен их нужно обновить вместе с настройками хостинга.

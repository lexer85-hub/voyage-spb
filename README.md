# Вояж-СПб — сайт магазина автозапчастей

Первая версия, 8 октября 2026 года. HTML, CSS, JavaScript; без сборщика, CMS, базы данных и сторонних библиотек.

## Что находится в архиве

- `dist/` — готовый сайт для размещения на хостинге.
- `branding/` — SVG-логотипы: основной для тёмного/светлого фона, альтернативный, чёрный и белый, значок сайта. Все надписи переведены в векторные контуры.
- `README.md` — эта инструкция.
- `QA.md` — выполненные проверки и ограничения.

## Локальный просмотр

Откройте `dist/index.html` в браузере. Для полноценной проверки карты и загрузки файлов лучше запустить из папки проекта:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

Затем откройте http://127.0.0.1:8765/ . Сервер доступен только на этом компьютере. Для карты нужен интернет.

## Карточки ассортимента

Карточки раскрываются по нажатию. Использованы стандартные HTML details/summary: доступны с клавиатуры (Enter / пробел), на сенсорных устройствах и без JavaScript. На компьютере сетка из трёх колонок, на планшете — двух, на телефоне — компактный список. Раскрытие увеличивает высоту строки без обрезания содержимого. Переворот при наведении удалён, чтобы текст не исчезал при движении курсора.
